# Task 008: Offline checks on every pull request (technical minimum #4)

## Goal
`.github/workflows/checks.yml` runs the model-free parts of the chain on every pull request.

## Context
- No model and no secrets in CI: stages 1–3 offline, the grant check, and the dry run
- `actions/setup-python@v5` makes `python` available on the runner, matching our local command
- Steps:
  ```yaml
  - uses: actions/checkout@v4
  - uses: actions/setup-python@v5
    with: { python-version: "3.12" }
  - run: python harness/entity.py fixtures/input_hamar.json --offline
  - run: python eval/check_entity.py
  - run: python eval/check_grants.py
  - run: python harness/filter.py fixtures/input_hamar.json --today 2026-10-30
  - run: python eval/check_filter.py
  - run: python eval/check_run.py
  ```
- Push rejected with "workflow scope"? `gh auth refresh -h github.com -s workflow` (W43 backup slide)

## Constraints
- Do not edit eval/
- No secrets in the workflow file

## Acceptance (all must pass)
- A PR shows the check green
- Break it on purpose (e.g. change `region_prefix` in one grant file), see red, revert, see green.
  Screenshot both for the report; one prompt-log line
- `git tag c2-skeleton && git push origin main --tags`

## Out of scope
Scheduled live runs (only after task 010 respects the sources' terms)
