# Spec

## Problem

Local volunteer organizations in Innlandet lack the time and administrative capacity to navigate fragmented, highly bureaucratic municipal and county grant schemes, often causing them to miss critical funding opportunities.

## Users

Board members, treasurers, and project leaders of local volunteer organizations (e.g., sports clubs, youth groups, cultural associations) operating in the Innlandet region.

## Definition of success

The workflow takes an official Organization Number and a short project idea, and outputs a plain-language application checklist with a structured JSON summary of eligible grants. Success is achieved when an automated evaluation script can mechanically verify that all outputted deadlines, URLs, and eligibility rules perfectly match the source grant documents and official Brønnøysund API data, with strictly zero personal data included.
