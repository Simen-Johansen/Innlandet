# Søknadsplan for tilskudd: RINGEBU FÅVANG TUR- OG TRIM KLUBB

Organisasjonsnummer: 994414682  
Generert: 12.11.2026

Automatisk kontrollert mot de offisielle kildene hentet 28.10.2026. Bekreft alltid fristen på tilskuddssiden før dere søker.

## [Tilskudd til friluftslivsaktivitet](https://innlandetfylke.no/tjenester/sok-tilskudd/idrett-og-friluftsliv/tilskudd-til-friluftslivsaktivitet.36453.aspx)

- **Søknadsfrist:** 01.12.2026
- **Maksbeløp:** Ikke oppgitt på tilskuddssiden
  Dere ber om 60000 NOK. Tilskuddssiden oppgir ikke noe maksimalt beløp, så dere bør spørre tilskuddsgiveren.

### Hvorfor dere kvalifiserer

Dere er en frivillig organisasjon som jobber med friluftsliv. Fellesturer og teltovernatting for ungdom er organisert friluftslivsaktivitet som gir økt deltakelse i friluftsliv, og det er det tilskuddet skal støtte.

### Vedlegg

- [ ] Tilskuddssiden oppgir ingen obligatoriske vedlegg. Sjekk søknadsskjemaet for å se hva dere må legge ved.

### Steg

1. Les om ordningen på siden til Innlandet fylke og på søknadsportalen til Miljødirektoratet.
2. Spør tilskuddsgiveren hva som er maksimalt beløp, siden det ikke står på siden.
3. Beskriv fellesturene og teltovernattingene for ungdom 13–16 år i prosjektet deres.
4. Send én samlet søknad via det elektroniske skjemaet på søknadsportalen til Miljødirektoratet.
5. Bekreft søknadsfristen på tilskuddssiden før dere søker.
